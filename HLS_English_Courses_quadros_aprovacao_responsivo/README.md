# HLS English Courses — Apresentação responsiva

Abra `index.html` no navegador. O arquivo foi organizado para facilitar trocas de imagem.

## Como substituir as imagens

1. Abra a pasta `assets/`.
2. Substitua o arquivo desejado mantendo exatamente o mesmo nome.
3. Reabra ou atualize `index.html`.

| Arquivo | Uso principal |
|---|---|
| `01_livro_azul.jpg` | Capa e livro azul em destaque |
| `02_colecao_laranja.jpg` | Coleção de livros e livro laranja |
| `03_reading_comprehension.jpg` | Reading & Comprehension e encerramento |
| `04_colecao_expositor.jpg` | Progressão de níveis e coleção |

As imagens são externas ao HTML de propósito: isso reduz o tamanho do arquivo e torna a substituição simples.
